# Лабораторная работа № 1: Обработка и очистка данных (Yelp Open Dataset)

Дисциплина: «Введение в анализ данных и программирование на Python»

## Описание проекта
Полный маршрут подготовки данных: от развёртывания рабочего окружения и сериализации исходного набора данных Yelp в бинарный колоночный формат Parquet до очистки и загрузки нормализованной схемы (3НФ) в СУБД SQLite и PostgreSQL.

## Требования к окружению
* Интерпретатор: **Python 3.12.14**
* Менеджер зависимостей: **Poetry**
