# Паспорт набора данных: Yelp Open Dataset

## 1. Общие сведения
* **Наименование набора:** Yelp Open Dataset (Academic Dataset)
* **Источник данных:** Официальный портал Yelp для бизнеса
* **Формат хранения:** JSON Lines (.json), кодировка UTF-8
* **Общий объём исходных файлов (data/raw/):** 8 861,19 МБ (8,65 ГБ)
* **Отладочный срез (data/interim/review_sample_200k.jsonl):** 200 000 записей (142,46 МБ)

## 3. Обнаруженные дефекты данных (План очистки для Шага 12)
1. **Неоптимальные типы:** даты хранятся как строки, счётчики занимают 8 байт (int64), категории и города — object вместо category.
2. **Скрытые пропуски:** пустые строки "" в текстовых полях, отрицательные значения в счётчиках голосов (useful, unny).
3. **Несогласованность категорий:** разнобой регистра в названиях городов (Philadelphia, philadelphia), краевые пробелы.
4. **Нарушение нормальных форм:** вложенные структуры в ttributes, хранение списков через запятую в categories.
